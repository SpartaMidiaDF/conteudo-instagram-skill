# Biblioteca universal de carrossel

Padrões que se repetem nos carrosséis que mais engajam, em qualquer nicho. A **base de conhecimento do nicho** (feita a partir dos concorrentes) diz *quais* destes padrões o público responde e com *quais* palavras. Na dúvida, a base do nicho vence esta biblioteca.

## 1. Ganchos (capa)

| Código | Tipo | Como funciona | Exemplo genérico |
|---|---|---|---|
| G1 | Pergunta-dor direta | Nomeia a dor em 2ª pessoa | "Seu cabelo quebra mesmo hidratando?" |
| G2 | Mito entre aspas + "Será?!" | Cita a crença e duvida | "'Carboidrato à noite engorda.' Será?!" |
| G3 | Absolvição | Tira a culpa, gera alívio | "Não é falta de disciplina. É o método." |
| G4 | Caso real | Cena + curiosidade (só se for real) | "Uma cliente chorou quando viu o resultado…" |
| G5 | Lista numerada com autoridade | Número + credencial | "7 erros que eu não cometo porque sou nutricionista" |
| G6 | Metáfora inesperada | Imagem do cotidiano que só faz sentido ao deslizar | "Você já desceu num tobogã sem água?" |
| G7 | Confissão / segredo | Promete o que ninguém fala | "O que as pessoas escondem até das melhores amigas…" |
| G8 | Intimidade / amiga | Tom de melhor amiga | "Dicas que eu te daria se fôssemos amigas. E somos." |
| G9 | Promessa prática com prazo | Resultado concreto | "Se quiser dormir melhor essa semana…" |
| G10 | Curiosidade / tabu leve | A pergunta que todo mundo tem e não faz | "Pode lavar o cabelo todo dia?" |
| G11 | Dado / estudo | Número que provoca (com fonte) | "Só 1 em cada 5 pessoas faz isso direito" |
| G12 | Contraste "duas pessoas" | Mesma situação, resultado oposto | "Duas pessoas, o mesmo salário. Patrimônios opostos." |
| G13 | Formato meme / trend | Estrutura viral reaproveitada | "wtf is…", "acho chique…", "Posso pesar o clima?" |
| G14 | Provocação / manifesto | Opinião forte | "Autocuidado não é luxo. PASMEM!" |
| G15 | Fala com o outro | Imperativo para quem vai receber o post | "Marido, isso aqui é pra você." |
| G16 | Pergunta reflexiva | Abre pelo lado existencial | "Quando foi a última vez que você descansou sem culpa?" |
| G17 | Data comemorativa | Gancho de calendário | "Dia dos Namorados: 5 ideias que não custam nada" |
| G18 | Teste / autodiagnóstico | Quiz com pontuação | "Some os pontos: seu sono está no piloto automático?" |
| G19 | O que ela não sabe responder | Expõe a lacuna | "Você saberia explicar o que é juros compostos?" |

**Recursos de capa:** subtítulo de promessa ("e não é o que você pensa"), reticências, "arrasta para o lado →", palavra em destaque (itálico/cor), etiqueta de série ("Série X #3"), anotação à mão com seta.

## 2. Frameworks (estrutura slide a slide)

Regra de ouro: **uma ideia por slide**, frase curta, **última linha puxa o próximo** ("Mas a verdade é outra…").

- **F1 Mito × Verdade** — capa com o mito/promessa → contexto → um mito por slide (mito em destaque + verdade em 2–4 linhas) → reenquadre → CTA "manda para quem precisa".
- **F2 Metáfora-ponte** — metáfora → cena completa → conclusão óbvia na metáfora → "mas com [tema] fazemos exatamente isso" → distinção-chave → esperança → CTA.
- **F3 Caso real** — cena emocional → o que aconteceu → "vem que eu te explico" → raiz do problema → pergunta incômoda → libertação → frase de fechamento. *Só com caso real e autorizado.*
- **F4 Retrato-espelho** — frase que a persona diria → retrato em 3ª pessoa ("Ela…") → antes × agora → tentativas que falharam → o que ninguém contou → verdade → CTA.
- **F5 Lista prática** — problema + promessa → erro comum → passos numerados (título curto + 2–3 linhas) → insight nomeado → "salva".
- **F6 Uma frase por slide** — formato meme/trend, 8–10 frases curtas → pergunta "me conta".
- **F7 Comparação** — duas pessoas, mesma situação, caminhos opostos → "qual está errada? nenhuma" ou "a diferença é…" → conceito → pergunta.
- **F8 Bastidores** — fotos reais + legendas curtas; humaniza a marca.
- **F9 Curadoria "Repertório"** — série numerada; um item por slide com "por que vale" → "salva".
- **F10 Problema → produto** — dor → normaliza → causa → "não era X, era falta de Y" → produto como "ajudinha" + modo de usar → CTA "comente PALAVRA".
- **F11 Jogo / dinâmica** — ideias numeradas → mecânica final ("cada um escolhe 2 sem contar") → "manda para quem vai jogar com você".
- **F12 Pergunta repetida** — mesmo layout, "Depende. Mas…" com respostas diferentes.
- **F13 Ensaio / manifesto** — provocação → contexto cultural → "eu vejo…" → conceito → pergunta → frase-tatuagem.
- **F14 Dado com nuance** — pergunta do dado → estudo → nuance → lista → "me conta nos comentários".
- **F15 Prova social** — prints reais e autorizados de clientes/alunos.
- **F16 Quiz** — checklist com pontos → "somou mais de 3?" → CTA.

**Arco de lançamento:** 4–6 carrosséis na semana anterior a uma data/oferta, cada um por um ângulo diferente, todos com o mesmo CTA final.

## 3. CTAs

| Objetivo | CTA |
|---|---|
| Salvar | "Salva para consultar quando precisar" |
| Compartilhar | "Manda para a amiga que **sempre fala que…**" (nomear *quem* recebe é o gatilho mais forte) |
| Comentar | "Qual dessas você já fez? Me conta" · "Eu começo: …" |
| Comentário → direct | "Comente PALAVRA que eu te mando no direct" (precisa de automação ou resposta manual) |
| Continuação | "Comenta para ter a parte 2" |
| Seguir | "Me segue, aqui eu falo de X toda semana" |

## 4. Escrita

- **Ritmo:** a cada 3–4 frases, uma de até 5 palavras. Slide longo termina em frase curta de impacto.
- **Promessa explícita no slide 2.** Títulos como a pessoa busca no Google quando der.
- **Números só com fonte.** Experiência ("nossos clientes perguntam…") só se for real. Depoimento só real e autorizado.
- **Frases proibidas (soam a IA):** "No mundo de hoje", "É importante ressaltar", "Vamos mergulhar", "Descubra", "Confira", "Neste carrossel você vai", "Em resumo", "Por fim", frases começando com "Além disso,", "potencializar", "desbloquear", "elevar sua experiência", "robusto", "transforme sua vida". **Nunca proibir** o vocabulário que os concorrentes do nicho usam.
- **Capa, títulos e último slide** passam por uma segunda reescrita.
- **Autoridade:** a marca só fala como especialista se for. Senão: fonte citada, dado real da empresa ou especialista parceira identificada.

## 5. Mix de conteúdo (ponto de partida)

40% educação/identificação · 25% prático/dinâmica · 20% produto como solução · 15% comunidade/bastidores/trend. "Para cada 4 que ajudam, 1 vende — e o que vende começa ajudando."

## 6. Checklist antes de publicar

- [ ] Capa com gancho (G1–G19) + subtítulo de promessa
- [ ] Uma persona, um framework, uma ideia por slide, última linha puxando o próximo
- [ ] Identificação / "não é culpa sua" antes de qualquer produto
- [ ] Promessa no slide 2; ritmo com frase curta
- [ ] Nenhuma frase proibida; nenhuma palavra proibida da marca
- [ ] Nenhum número sem fonte, depoimento inventado ou promessa que o nicho proíbe
- [ ] Legenda: palavra-chave na 1ª linha (se houver), CTA específico, 3–5 hashtags limpas
- [ ] Texto alternativo em todos os slides
- [ ] Imagens dentro das regras do Instagram para o nicho
